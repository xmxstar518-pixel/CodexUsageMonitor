# Security Policy / 安全策略

Please do not disclose vulnerabilities in public issues. Send a private report through GitHub Security Advisories and include reproduction steps, impact, and a suggested fix when possible.

请勿在公开 Issue 中披露安全漏洞。请通过 GitHub Security Advisories 私下报告，并尽可能提供复现步骤、影响范围和修复建议。

Never include ChatGPT credentials, tokens, private account data, or unredacted diagnostic output in a report.

报告中请勿包含 ChatGPT 凭据、Token、私人账户数据或未经脱敏的诊断输出。
