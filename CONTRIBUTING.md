# Contributing / 参与贡献

Thank you for contributing. Please keep changes focused, avoid committing credentials or account data, and run `swift test` plus `./scripts/build_app.sh` before opening a pull request.

感谢参与贡献。请保持改动聚焦，不要提交凭据或账户数据，并在提交 Pull Request 前运行 `swift test` 与 `./scripts/build_app.sh`。

For UI text, update both Simplified Chinese and English. Bug reports should include the macOS version, app version, expected behavior, and sanitized error details.

界面文案需同时维护简体中文和英文。提交缺陷时，请注明 macOS 版本、应用版本、预期行为和已脱敏的错误信息。
